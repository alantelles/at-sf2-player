# Project Guidelines — AT SF2 Player

## Git Commits
- Always use **Semantic Commits** (Conventional Commits) to prefix every commit message, e.g.:
  - `feat:` — new feature
  - `fix:` — bug fix
  - `docs:` — documentation changes
  - `refactor:` — code refactoring without behavior change
  - `test:` — adding or updating tests
  - `build:` — build system (`Makefile`, `Dockerfile`) or dependency changes
  - `ci:` — CI/CD workflow changes (`.github/workflows/`)
  - `chore:` — maintenance, tooling, or project configuration
